# Paper Bag Works · Custom Paper Packaging Website

An independent, luxury, and eco-friendly custom paper bag brand website built with React 18, Vite, and Lucide Icons.

## Features
- **Brand Identity**: Fresh eco-luxury palette (Forest Green `#22563a`, Warm Off-White `#f8f7f4`, Kraft `#b89467`).
- **Product Collection**: 8 signature custom paper bag lines in a responsive 4x2 grid.
- **Factory & Partner Showcase**: German Heidelberg press equipment, automated bag lines, and global client testimonials (Disney, Sam's Club, Taiqi, Miniso, UNES, MENOW).
- **Interactive Floating Contact Widget**: Dedicated brand paper bag silhouette with instant WhatsApp & Phone call drawers.
- **Formspree AJAX Integration**: Custom quote form with asynchronous submission and file upload.
- **Full-Spectrum SEO**: Structured schema markup, rich meta tags, and optimized asset delivery.

## Tech Stack
- **Framework**: React 18 (SPA)
- **Build Tool**: Vite
- **Icons**: Lucide React
- **Styles**: Custom Vanilla CSS with Design System Variables

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
```
The compiled static assets will be output to the `dist/` directory, ready for deployment to Vercel, Cloudflare Pages, Netlify, or Nginx.
